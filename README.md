**Mechatronics Engineer | Robotics & Control Systems | Reinforcement Learning**

I am a Mechatronics Engineer with a strong interest in robotics, dynamic system modeling, control theory, and reinforcement learning.

My work focuses on mathematical modeling, control algorithm development, robotic simulation, and the integration of intelligent control techniques into dynamic systems.

I am particularly interested in bridging the gap between theoretical control methods, simulation, and real-world robotic applications.

## Research Interests

- Robotics: Robot dynamics, kinematics, modeling, and simulation.
- Control Systems: Classical Control, LQR, LQI, MPC, and NMPC.
- Reinforcement Learning: Learning-based control, policy optimization, and robotic applications.
- System Identification: Dynamic system analysis and parameter estimation.
- Embedded Systems: Microcontroller programming and real-time control systems.
